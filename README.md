A native Android notes application built with Jetpack Compose, MVVM/Clean Architecture, Room, Hilt, and Kotlin coroutines.

## Features

- Create notes
- Edit notes
- Delete notes
- Share notes
- Organize notes with categories
- Offline access

## Architecture & Tech

- Kotlin
- Jetpack Compose
- MVVM + Clean Architecture
- Navigation Components
- Dagger Hilt
- Room database
- Kotlin Coroutines

## Getting Started

Clone the repository:

```bash
git clone https://github.com/AlakhiarovSalekh/Notes-App.git
```

Open the project in Android Studio, synchronize Gradle, and run the `app` module on an emulator or Android device.

## Why this project

The repository demonstrates a modern Android stack with declarative UI, dependency injection, local persistence, asynchronous work, navigation, and layered architecture.
